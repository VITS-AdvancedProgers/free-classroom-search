# Свободные аудитории — Б корпус

Минимальный интерфейс на Next.js App Router, React и Tailwind CSS v4.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Данные

Демонстрационные аудитории и занятия находятся в `data/rooms.ts`.
Каждый элемент `lessons` соответствует паре по порядку: 1–6. `null` означает,
что аудитория свободна. Замените демонстрационные данные реальным расписанием.

## Структура

- `app/page.tsx` — интерфейс и фильтрация
- `app/globals.css` — стили
- `app/layout.tsx` — корневой layout
- `data/rooms.ts` — демонстрационные аудитории
